# 🎬 Movie-Finder

Movie-Finder is a web application that helps users search for movies and view details such as ratings, release year, genre, and plot summaries. It uses the OMDb API to fetch accurate movie information and presents it in a simple, responsive interface.

---

## ✨ Features
- 🔍 Search movies by title
- 📅 View release year
- ⭐ Display IMDb ratings
- 🎭 Show genre and plot summary
- 📱 Responsive design for desktop and mobile

---

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript  
- **API:** [OMDb API](https://www.omdbapi.com/)
